# Dr. Maya Reynolds, PsyD — Therapy Homepage

Responsive single-page therapist website built with React + Vite.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

### Included
- Responsive desktop/tablet/mobile layout
- Maya profile content and supplied profile images
- Original-template-inspired section flow
- Custom "Our Office" section
- FAQ accordion
- Accessible anchor navigation
- SEO title/description
"# dr-maya-reynolds-therapy-website"
